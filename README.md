# 🧮 Calculator Web App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations and demonstrates fundamental web development skills.

---

## 🚀 Features
- Basic arithmetic operations (+, −, ×, ÷)
- Clear display functionality
- Error handling for invalid expressions
- Responsive and clean UI design
- Interactive button clicks

---

## 🛠️ Technologies Used
- HTML5 – Structure of the application  
- CSS3 – Styling and layout design  
- JavaScript – Logic and calculations  

---

## 📂 Project Structure
Calculator/
│── index.html
│── style.css
│── script.js

---

## ▶️ How to Run
1. Download or clone the repository  
2. Open `index.html` in your browser  
3. Start using the calculator  

---

## 📸 Output
Simple calculator interface with buttons and display screen.
